# Dotfiles-Hyprland

Personal Hyprland configuration.

## Contents

- `config/` — Lua-based Hyprland config modules (binds, animations, monitors, inputs, etc.)
- `scripts/` — helper scripts (screenshot, volume, brightness, waybar, wlogout, etc.)
- `colors.conf`, `hyprlock.conf`, `hypridle.conf`, `hyprpaper.conf`, `xdph.conf` — supporting configs
- `hyprland.lua` — entry point

## Usage

Symlink or copy this directory to `~/.config/hypr`.
